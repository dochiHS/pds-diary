# 자동 검사

로컬에 Supabase와 같은 구조를 만들어(PostgreSQL 16 + PostgREST 12.2.3, `anon` 역할·`/rest/v1` 경로·`apikey` 헤더 검사)
`supabase/schema.sql`을 그대로 올린 뒤 검사했습니다. 브라우저 시간대는 일부러 서울이 아닌 `America/Los_Angeles`로 두어
화면 시각이 브라우저 시간대와 상관없이 서울 시간으로 나오는지도 함께 봤습니다.

- `api_test.py` — DB 함수(RPC) 직접 호출 검사 51개: 계획 수정 이력, 완료 5번 동시 요청(같은 키·다른 키), 시간대 변환,
  집계를 따로 짠 SQL과 비교, 표 직접 접근 차단, 내부 함수 호출 차단 등
- `e2e.mjs` — 실제 화면을 Playwright로 눌러 보는 검사 43개(아래 표)
- `devserver.mjs` — 로컬 검사용 서버(화면 파일 + `/rest/v1` → PostgREST 중계, publishable 키 검사)

## 다시 돌려 보기

```bash
# 1) PostgreSQL에 anon·authenticated·authenticator 역할을 만들고 supabase/schema.sql 실행
# 2) PostgREST를 :3000에 띄움 (db-anon-role = anon, db-schemas = public)
node checks/devserver.mjs &          # :8080
python3 checks/api_test.py           # DB 함수 검사 (빈 DB에서 실행)
node checks/e2e.mjs                  # 화면 검사 (시작할 때 표를 비움)
```
